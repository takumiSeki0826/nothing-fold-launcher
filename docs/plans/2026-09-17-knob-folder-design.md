# ノブのフォルダ化とEQ画面廃止 設計書

## 背景

現在、ホーム画面のノブ（HOME_1 / HOME_2）は長押しで2つ目のアプリを直接起動する仕様になっている。また、ホーム画面から左スワイプすると「EQ画面」（6個のロータリーノブが並ぶ、タップ/長押しでアプリを起動できる画面）に遷移する。

この設計では:
1. ホームノブの長押しを「単一アプリ起動」から「フォルダ（複数アプリ）を開く」挙動に変更する
2. 左スワイプのEQ画面を完全に廃止する
3. ホーム画面のアプリ一覧（グリッド）に、フォルダを表す「フォルダノブ」を新規に追加できる機能を作る

## 1. データモデルとホームノブの変更

### フォルダの概念
`名前 + アプリのパッケージ名リスト` を「フォルダ」として扱う。ホームノブの長押し割り当てと、アプリ一覧グリッド上のフォルダノブの両方で、この概念を使い回す。

### ホームノブ（HOME_1 / HOME_2）
- **タップ**: 現状維持。単一の割り当てアプリを起動する。
- **長押し**: 割り当てられたアプリのリストが空でなければ、フォルダオーバーレイを表示（アプリアイコン一覧、タップで起動）。空であれば複数選択のアプリ選択画面を開き、選んだアプリをそのノブのフォルダとして保存する。
- **永続化**: `HomeKnobAssignmentStore` の長押し用の値を「単一パッケージ名の文字列」から「カンマ区切りのパッケージ名リスト」に変更する。既存の単一パッケージ名の値はカンマを含まない1件のリストとしてそのまま読めるため、データ移行処理は不要。
- **設定メニュー**: `HomeKnobSettingsMenu` の「Hold: X」表示を「Folder: N個のアプリ」に変更し、押すと複数選択画面（チェックボックス）が開くようにする。

### 左スワイプ（EQ画面）の廃止
`HomeRoute.EQ` および左スワイプでの画面遷移ロジックを完全に削除する。EQ画面・EQノブ・その割り当てデータに関するコードは全て削除し、再利用しない。

## 2. アプリ一覧グリッドへの「フォルダノブ」追加

- **データ**: 新規ストア `HomeAppFolderStore` を追加し、`id / 名前 / パッケージ名リスト` を持つフォルダを複数（上限なし）永続化する。
- **一覧への統合**: アプリ一覧グリッドが扱うアイテムを「アプリ」と「フォルダ」を混在させたリストとして扱えるようにする（sealed typeで表現）。フォルダは一覧の末尾に追加される（並び替えは今回のスコープ外）。
- **見た目**: グリッドの1タイル分のサイズで、中身は既存の `RotaryKnob` と同じビジュアル（円形ノブ＋中央にフォルダ名）。他のアプリアイコンと並んで表示される。
- **操作**:
  - タップ → フォルダの中身をオーバーレイ表示（アプリアイコン一覧、タップで起動、タップ後は自動的に閉じる）
  - 長押し → 編集ダイアログ（名前変更・中身のアプリ再選択・フォルダ削除）
- **作成方法**: アプリ一覧の空白部分を長押しすると新規の「アプリ一覧設定」メニューが開く。ここに既存フォルダの一覧（編集への導線）と「＋ フォルダを追加」ボタンを表示する。追加時は名前入力とアプリの複数選択（チェックボックス）を行い、確定するとグリッド末尾に新しいフォルダノブが追加される。
- **フォルダ削除**: フォルダの参照（名前とパッケージ名リスト）を削除するのみで、中のアプリ自体はアンインストールされない。

## 3. 共通UI

- **複数選択ピッカー**: 既存の `AppDrawer`（検索＋アルファベット索引付きの一覧）にチェックボックス選択モードを追加し、ホームノブのフォルダ編集・グリッドのフォルダ編集の両方で使い回す。
- **フォルダオーバーレイ**: フォルダの中身（アプリアイコン一覧）を表示する新規コンポーネント。既存ダイアログ（`HomeKnobSettingsMenu`など）と統一感のあるダークテーマのスタイルにする。タップで起動、タップ外や戻るで閉じる。

## 4. 影響ファイル一覧

**削除:**
- `ui/EqScreen.kt`
- `ui/EqKnobSettingsMenu.kt`
- `data/EqKnobAssignmentStore.kt`
- EQ用の `KnobSlot` 定義

**変更:**
- `ui/HomeGestureMath.kt` — `HomeRoute.EQ` と左スワイプ判定を削除
- `MainActivity.kt` — EQ関連の状態/コールバックを削除。ホームノブ長押し処理をフォルダ用に変更。フォルダオーバーレイ・複数選択の状態管理を追加
- `data/HomeKnobAssignmentStore.kt` — 長押し用の値をカンマ区切りリスト対応に変更
- `ui/HomeKnobSettingsMenu.kt` — 「Hold」表示をフォルダ表示に変更
- `ui/HomeScreen.kt` / `AppGrid` — アプリ/フォルダ混在リスト対応、フォルダタイル描画追加、グリッド空白長押しで新設定メニューを開くジェスチャー追加
- `ui/AppDrawer.kt` — 複数選択モード（チェックボックス）追加
- `ui/AppListViewModel.kt` — ホーム画面向けの一覧をアプリ/フォルダ混在の形に変更し、`HomeAppFolderStore` から読み込み

**新規:**
- `data/HomeAppFolderStore.kt` — グリッド用フォルダの永続化
- `ui/FolderOverlay.kt` — フォルダの中身を表示するオーバーレイ
- `ui/HomeAppGridSettingsMenu.kt` — グリッド空白長押しで開く、フォルダ追加/一覧/編集への導線

## スコープ外

- フォルダやアプリの並び替え（ドラッグ＆ドロップでの順序変更）
- グリッド上のフォルダノブ数の上限
- EQノブのデータ構造の再利用（完全廃止のため）
