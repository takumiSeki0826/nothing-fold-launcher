# ホーム画面アプリ一覧の配色パターン 設計

## 背景

ホーム画面のアプリ一覧（2行×4列グリッド）に、ランチャーのメインカラー4色（黒 `#000000`・白 `#FFFFFF`・グレー `#8A8A8A`・アクセントの赤オレンジ `#D1432B`）を使った配色パターンを導入したいという要望。

以前は `IconPalette.kt` に `index % 4` でパレットを循環させる仕組みがあったが、4列グリッドでは同じ列が常に同じ色になり単調になる問題があった。またその仕組みは直近の作業（未コミット）で「全アイコン黒背景＋アクセント枚縁の統一デザイン」に置き換えられた。今回はこの反省を踏まえ、単調さを避けつつアクセント色の「強調用の少数使い」という他画面（EQ、カレンダー等）との一貫性も保つ配色ロジックを設計する。

## 配色ロジック

先頭（グリッド上のインデックス0）は**モードに関わらず常にアクセント色 `#D1432B`**。残り7枚は黒・白・グレーの3色パレット `[Black, White, Gray]` から、以下いずれかのモードで色を決める。

- **位置ベース**: `colorIndex = (row + col) % 3`
  2行4列では次のようになり、同じ列が連続で同色にならず対角的に色が散らばる（黒2・白3・グレー2・アクセント1）。
  ```
  Row0: Accent, White, Gray,  Black
  Row1: White,  Gray,  Black, White
  ```
  この式は3行×4列（展開幅レイアウトの12枠）でも自然に一般化される。
- **識別ベース**: `colorIndex = stableHash(packageName) % 3`
  アプリの並び替え・入れ替えがあっても同じアプリは常に同じ色を保つ。8枚並んだときの色分布が偏る可能性はあるが、ユーザーはその特性を理解した上でこのモードを選べるようにしたいという要望。

2モードはユーザーが切り替えられるようにする（一方に決め打ちしない）。

## 見た目の変更点

- 変わるのは**アイコンタイルの背景色のみ**。
- 枚縁は全タイル常にアクセント色 `#D1432B`（背景と同色になる先頭タイルも含め、変更なし。枚縁と背景が同色でも、他タイルとの統一感を優先する）。
- ラベルの文字色は常に白（ラベルはタイルの下に配置され、背景色と接していないため無関係）。

## 設定UI・トリガー

- **トリガー**: ホーム画面の何もない余白の長押し。既存の `onHomeKnobSettingsLongPress`（展開幅レイアウトのスライダー/ノブ行に付与されている `detectTapGestures(onLongPress = ...)`）と同じパターンを、折り畳み時・展開時両方のレイアウトのルートコンテナに追加する。アイコンや他ウィジェットは自分自身の `combinedClickable`/`onLongClick` で先にイベントを消費するため、既存の長押し操作と競合しない。
- **設定ダイアログ**: `HomeKnobSettingsMenu.kt` と同じ見た目（`AlertDialog`、黒背景・白文字）の小さなメニューを新規作成し、「位置ベース」「識別ベース」を選ぶラジオ選択にする。

## 永続化

`EqKnobAssignmentStore.kt` / `HomeKnobAssignmentStore.kt` と同じ DataStore パターンで、選択中のモード（1件のenum値）を保存する小さなストアを新規作成する。

## テスト方針

`IconPaletteTest.kt` で以下を検証:
- index 0 は常にアクセント
- 位置ベース: 8枠での `(row+col)%3` の出力パターンが期待通り（同一列が連続同色にならないこと）
- 識別ベース: 同一パッケージ名は常に同じ色（安定性）、パッケージ名が変われば分布が3色内に収まること

実機での手動確認:
- 折り畳み時・展開時（12枠）両方でグリッドの配色が意図通りであること
- ホーム画面余白の長押しでダイアログが開き、モード切り替えが即座に反映されること
- アプリ起動・長押しメニューなど既存操作にregressionがないこと
