# ホーム画面アプリ/フォルダのドラッグ並び替え & カバー画面8スロット化 設計書

## 背景

ホーム画面のノブ（円形の見た目）がアプリタイルに比べて小さく見えていたため、見た目のサイズを揃えた（`RotaryKnob`の塗りつぶし円の半径を`knobRadius * 0.85f`から`knobRadius`に変更し、タイル全体を使うようにした）。

加えて、ホーム画面のアプリ/フォルダタイルの並び順を、ユーザーがドラッグで自由に入れ替えられるようにしたい。特に折りたたみ時（カバー画面）は「8つの穴の中でタイルを移動する」というイメージで、固定8スロットのグリッドにする。

## 1. 並び順の永続化モデル

現在、ホーム画面の並び順は「お気に入り登録アプリを全アプリ順でフィルタしたもの＋フォルダを作成順で末尾に追加」という暗黙の順序になっている。ドラッグ並び替えのために、明示的な順序リストを永続化する。

- 新規ストア `HomeOrderStore`：`"app:<packageName>"` または `"folder:<folderId>"` 形式の参照文字列を、順序付きでカンマ区切り保存する（既存の`encodePackageList`/`decodePackageList`を再利用）
- `AppListViewModel`の`homeItems`算出ロジック:
  1. 保存済みの順序リストを読み込む
  2. 現在有効な項目（お気に入りアプリ＋存在するフォルダ）だけに絞り込む
  3. 保存済み順序に無い新規項目（新しくお気に入りにしたアプリ、新規作成フォルダ）は末尾に追加
  4. 整えた順序を保存し直し、`HomeGridItem`のリストに変換
- 展開時・折りたたみ時で順序リストは共有する（折りたたみ時は先頭8件だけ表示、展開時は従来通り先頭12件まで表示）
- 並び替え確定時（スワップ/移動）は、この順序リストを直接書き換えて永続化する

## 2. カバー画面（折りたたみ時）の固定8スロット化

- 折りたたみ時のグリッドは常に2行×4列＝8スロット表示に固定する（列数は既存の`homeGridColumns`の4のまま、新しく`coverGridMaxItems() = 8`のような上限関数を追加）
- 順序リストの先頭8件を表示。9件目以降はカバー画面には表示されないが、展開時の一覧やドロワー検索からは引き続きアクセス可能
- 8スロットのうち埋まっていない位置は「空の穴」として可視化する。ブランドカラー以外のグレーを直書きしない方針に沿い、`Color.Gray`（プレースホルダー用途のグレー）の枠線だけの円をタイルサイズで描画し、背景は塗らない
- 空の穴にもドラッグでアイテムを移動できる（この場合は入れ替えではなく「移動」）

## 3. ドラッグ操作の設計

- **開始**: タイルを長押しし、指を離さずに動かすとドラッグ開始。長押し後に指を動かさずそのまま離せば、従来通りのコンテキストメニュー（アプリ）／フォルダ編集ダイアログ（フォルダ）が開く。同じ長押しジェスチャーから、移動距離のしきい値で分岐する
- **ドラッグ中の見た目**: つまんだタイルが指に追従してやや拡大表示され、他のタイルの上を通過すると通過先のスロットがハイライトされる
- **ドロップ時の確定**:
  - 別の埋まっているタイルの上で離す → その2つの位置を入れ替える（スワップ）
  - 空の穴の上で離す → そこへ移動する（元の位置は空になる）
  - グリッド外や無効な位置で離す → 何も起きず元の位置に戻る
- **実装方針**: 各タイルの画面上の矩形位置を記録しておき、ドラッグ中の指の位置と比較して最も近いスロットを判定する、自前実装のドラッグ&ドロップグリッド方式を取る。座標→スロット番号の判定ロジックは純粋関数として切り出し、既存の`HomeGestureMath.kt`等と同様にユニットテスト可能にする
- 展開時・折りたたみ時どちらのグリッドも同じ仕組みを共有する（タイルサイズや列数が異なるだけ）

## 4. 影響ファイル一覧（想定）

**新規:**
- `data/HomeOrderStore.kt` — 明示的な並び順の永続化
- `ui/HomeGridDragMath.kt` — 座標→スロット番号判定などの純粋ロジック（テスト対象）

**変更:**
- `ui/AppListViewModel.kt` — `homeItems`算出を順序リストベースに変更、スワップ/移動メソッドを追加
- `ui/HomeScreen.kt`／`AppGrid` — ドラッグジェスチャー、空きスロット描画、カバー画面8件上限の適用
- `ui/HomeLayoutMath.kt` — `coverGridMaxItems()`追加
- `ui/RotaryKnob.kt` — 塗りつぶし円のサイズ調整（実施済み）

## スコープ外

- フォルダの中身（フォルダ内のアプリ）の並び替え
- グリッド間（カバー画面⇔展開時）をまたぐドラッグ操作
