# ミニマルなカラーブロックアイコン ＋ クリーンな時計タイポグラフィ 設計

## 背景

参考動画（「究極にミニマルなホーム画面」的な内容のYouTube動画、535秒時点のスクリーンショット）を見て、より統一感のあるミニマルなデザインに寄せたいという要望。黒背景は維持しつつ、アイコンの統一感とレイアウトのミニマルさだけを取り入れる方向で合意した。

参考画像の特徴:
- クリーム色背景、上部に再生中メディア情報＋ドットのEQビジュアライザー（今回は見送り）
- クリーンなサンセリフフォントの時計（左に大きく時刻、右上に小さく日付）
- 単色の角丸四角形ブロックのアプリアイコン（実ロゴは使わず、ラベルで区別）

## スコープ

1. 時計をドットマトリクス描画からクリーンなタイポグラフィに変更
2. アプリアイコンをハーフトーン処理から単色角丸四角形ブロックに変更（黒/白/オレンジ/グレーを自動循環割り当て）

対象外（今回は見送り）:
- 背景色の変更（黒背景を維持）
- 上部の再生中メディア情報＋EQビジュアライザー

## 時計

- `ui/DotMatrixClock.kt`のドット描画ロジックを削除し、通常のCompose `Text`による時刻表示に置き換える
- レイアウト: 左に大きく`HH:mm`、右上に小さく日付（`MM.dd EEE`程度）
- フォントは既存の`NothingTypography`のsans-serifスタイルを使う（モノスペースの太字ではなく、細めのウェイト）

## アプリアイコン

- `ui/IconRenderer.kt`のハーフトーン処理（`renderHalftoneIcon`）を撤去し、単色角丸四角形ブロックの描画に置き換える
- 実際のアプリアイコン画像は使わない。色は固定パレット（黒/白/オレンジ/グレーの4色）をアプリ一覧の表示順で自動循環割り当てする
- 色割り当てのインデックス計算は `ui/IconPalette.kt` に純粋関数として切り出し、JUnitでテストする（`AppFilter`/`DotMath`と同じ方針）
- ホーム画面のグリッドと検索ドロワーの両方に同じスタイルを適用する

## 音量バー

- 既存のドットバー（`ui/VolumeBar.kt`）は変更なし。今回のスコープ外

## テスト方針

- `ui/IconPalette.kt`の色インデックス割り当てロジックをJUnitでテスト（境界値・循環の折り返しを確認）
- 実機で以下を手動確認:
  - アプリアイコンが単色の角丸四角形ブロックになっていること
  - 時計がクリーンなタイポグラフィで表示されていること
  - 既存の音量バー・アプリ起動などの機能に regression がないこと
